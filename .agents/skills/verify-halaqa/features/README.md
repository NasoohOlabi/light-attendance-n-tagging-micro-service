The historically named files exercise Railway-compatible same-origin boundaries.

`e2e/notebook.spec.ts` drives the sample notebook. `e2e/home.spec.ts`, `e2e/home-routing.spec.ts` and `e2e/wartaq.spec.ts` cover homepage, routing and design samples. `e2e/mobile.spec.ts` and the Arabic authentication case cover language, responsive controls and RTL. `e2e/pwa.spec.ts` tests public shell caching, private request bypass, prompt wiring and the bilingual update notice and Refresh button on desktop and mobile; its install prompt is simulated. Native OS installation remains unverified. See [PWA behavior](../../../../docs/pwa.md) and [mobile audit](../../../../docs/mobile-and-languages.md).

The notebook opens on a dashboard. Verify selected-date status counts include unmarked students and the recent chart counts present students on up to five recorded dates through the selected date, including zero-present dates, using effective projection. Take attendance opens the alphabetized course roster; drafts survive search and filter changes. Add student opens the creation form for Administrators and sample users, without granting Teacher access. `e2e/dashboard.spec.ts` exercises these dashboard paths. Administrators open Settings explicitly. Course schedule details are placeholders; enrollment details are managed in Courses. Retain only synthetic screenshots and traces.

Table controls: `e2e/table-controls.spec.ts` verifies filtered bulk attendance and hidden drafts. `e2e/table-pages.spec.ts` exercises every data header across all nine table surfaces, numeric grade order with empty values last, percentage matching, combined filters/reset, dates, language changes and malformed/stale URLs plus reload/Back. Keep keyboard operation, 44px targets and visible controls that fit desktop and phone widths. In attendance, filter to a subset and mark displayed students present; confirm hidden drafts remain unchanged and filters remain usable when no rows match. Existing course/roster scenarios retain action and geometry coverage after reordering.

At 320/390/430px in English and Arabic, verify roster, the attendance roster, summary, administrator register, course list, membership and grades, profile history, and student attendance history fit without horizontal table scrolling. Check labelled values and direct controls; retain desktop columns and confirm course levels and student privacy.

Record actions use three-dot menus on Courses, Grades, and History & corrections. Review the menus alongside the direct actions in other views. Dashboard, Attendance, membership and form submissions keep their primary controls visible. Attendance rows show Add note next to the attendance control. Students and the Administrator register keep their single Open student and Edit actions. Account management keeps password reset beside its fields. Profile actions, overview filters, student portal refresh and public navigation use their existing controls.

Unsorted headings show Lucide chevrons on pointer hover or keyboard focus, with an 8px label gap and no size change on reveal. Active sort direction and priority remain visible; on devices without hover, all chevrons remain visible. `e2e/table-controls.spec.ts` checks idle/hover/focus, pointer cursor, ascending/descending/reset icons and spacing in English/Arabic; course geometry checks measure the label independently of its decorative icon.

Open Sort to add, remove, change direction and drag column pills into priority order without duplicates. Exercise mouse/touch and keyboard reorder/drop/cancel, actual tied-row order, URL persistence and preview positioning under the production CSP. Open Filter on another table to select columns, combine text/choice conditions, edit/remove conditions and reset without losing hidden drafts. Verify popup close controls, Escape/outside dismissal and appropriate focus return. First Escape during keyboard drag cancels reordering; further Escape closes configuration. Switching languages must update screen-reader instructions. Check single-header/Shift-click shortcuts, reload, stale URL recovery and Grades' ignored stale filters. Verify English/Arabic desktop and 320/390px closed/open layouts, bounded popup scrolling and 44px targets. Configuration must not send writes.
