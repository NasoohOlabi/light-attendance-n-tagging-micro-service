# Assigned students

Sign in as an approved Teacher and verify Attendance, Students, Notes, Summary and History show only active assigned students. Use the open-student control and return to all students. `e2e/neon.spec.ts` checks that retry rejects a student removed from the current assignment; `e2e/roles.spec.ts` exercises Administrator assignment and roster creation. `tests/neon-api.test.ts` tests server-side scope and denials. Use synthetic fixtures only. Reassignment changes staff access to historical events; student access follows the linked student ID.
