# Assigned roster

Administrators maintain the complete student register, including historical students without a teacher assignment. Assignment controls Teacher access; it does not determine whether a student record is retained. Unassigned students display **Unassigned** in Settings and can be edited, kept inactive or assigned to an approved active Teacher later. Existing provisional or inactive assignments may be preserved while editing a profile; they cannot be newly assigned. Ignore the unmaintained old/former source flag and preserve stable IDs on roster updates. Keep real data outside Git and use the private CLI in [Railway setup](railway-setup.md) when importing.

The server checks the authenticated role, active state, expiry, Teacher access mode and current assignment. Teachers see active assigned students and can submit student-specific attendance and notes according to their mode. Reassignment changes staff access to the student's history. Administrators have the full notebook; Students receive only their own projected attendance. Signup alone grants no access. See [roles](roles.md).

Administrator student forms store optional WhatsApp number, general location and birth year (year only), alongside the existing roster level. Blank values clear these fields; legacy updates that omit them preserve them. They are not exposed in Student attendance responses.

The notebook Students table puts **First name**, **Last name**, **Phone** and **Attendance** first. Phone uses the stored contact value and remains isolated left-to-right; missing values show localized **Not provided**. Attendance shows Present divided by effective recorded sessions, rounded to one decimal, alongside a labelled session count. Unmarked days are excluded; no records shows **Not recorded**. All students summarizes every accessible course and unscoped attendance; selecting a course scopes these figures to that student's enrollment. Explicit name parts are preserved; legacy unsplit names stay intact without guessing a surname.

**Open student** opens a separate, reloadable **Student information** page with first/last names, the prominent phone field, attendance totals (Present, Absent, Excused, recorded sessions and percentage), courses and effective attendance history. A separate **Take attendance** action appears only when the student and chosen attendance context are eligible. Back returns to the list; browser Back/reload preserve the selected record and course. Inactive historical students remain readable by Administrators with their recorded history but cannot receive new attendance or notes. Teachers receive only their active assigned student profiles; the Student portal continues to expose only its own attendance projection, without these staff contact fields.

Spreadsheet recovery respects explicit phone number formats: numeric cells with zero placeholders retain their displayed leading zeros. It does not invent country prefixes, clear an owner's changed contact value or create phone numbers where the source is blank. Keep the workbook, source mapping and repair backup private.

Settings lists active and inactive students. In the Administrator notebook, **Students** defaults to **All students** and shows the complete register, including inactive and unassigned historical students. The count includes this full register; name and group filters narrow the table. Selecting a course retains its existing membership scope. Teachers' All students remains limited to their active assigned students. Current attendance and dashboard use active students; course history retains its existing membership scope. Historical students can remain inactive without being deleted or being given invented attendance, enrollments or teacher identities. Recover explicit source name parts and contact details when present; derive only the birth year from a dated birth field, and leave unavailable information blank.

The labelled **Courses** column shows each currently enrolled course as a separate named badge, independently of the roster level or selected course's enrollment level. Every name remains available when a student has several courses; no active enrollments displays localized **None**. Closed courses remain listed while membership is active; withdrawn memberships are excluded. Wide layouts show the course names directly; narrow phones provide an expandable labelled course list. Entering Students from another destination returns to All students, and an explicit course filter survives reload.

Notebook Students and attendance tables give the remaining width to student names. Level, status and action columns have compact, stable widths, with centered headers and values. Text direction is isolated inside cells so Arabic, Latin names and short level values stay aligned. Phone tables retain their labelled columns within bounded horizontal scrolling.

Tables offer a sort button and filter for each data column. Sort cycles ascending, descending, and original order; empty values sort last. The clear control resets the table's sorting and filters. Status filters select an exact value; other filters use text matching, including rounded displayed percentages. Table state is kept in the URL for navigation. On attendance, bulk marking affects only the rows matching all current filters; drafts for hidden students remain available.
